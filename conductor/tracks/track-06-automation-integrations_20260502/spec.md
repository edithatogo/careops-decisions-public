# Track 06: Automation Integrations

## Goal

Implement Power Automate flows for Microsoft 365 follow-through.

## Scope

- Planner task sync.
- Teams summaries.
- Outlook invite integration.
- Office 365 Users hierarchy lookups.
- SharePoint file registration.
- Reminders.
- Integration logging.

## Acceptance Criteria

- Flow contracts are implemented or represented as source-ready specs.
- Idempotency and failure logging are covered.
