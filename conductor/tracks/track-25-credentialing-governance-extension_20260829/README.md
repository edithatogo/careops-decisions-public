# Track 25: Credentialing governance extension

Status: in progress

This track adds a disabled-by-default credentialing governance capability pack
to Decisions Workspace. It preserves the distinction between intake,
professional judgement, committee recommendation, delegated decision,
authoritative register activation, review, appeal, and process assurance.
