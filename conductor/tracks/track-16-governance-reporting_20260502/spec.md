# Track 16: Governance Reporting

## Goal

Make reporting a first-class implementation stream covering operational Dataverse views, app dashboards, and future Power BI/Fabric analytics.

## Scope

- Dataverse views for chairs, secretaries, members, auditors, and administrators.
- App dashboard requirements for agenda readiness, minutes approval, decisions, actions, integration failures, and audit review.
- Metric dictionary for governance health, meeting performance, decision performance, action performance, records performance, AI performance, integration performance, and access/audit.
- Future Power BI/Fabric semantic model boundaries and row-level security assumptions.

## Acceptance Criteria

- Reporting metrics have source tables, filter rules, security assumptions, and acceptance examples.
- MVP reporting can run from Dataverse views before Power BI exists.
- Future Power BI/Fabric work has a clear model boundary and does not block the MVP.
