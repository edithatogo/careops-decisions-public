# Track 02: Template And Kit Evaluation

## Goal

Evaluate Microsoft/open-source Power Platform templates and kits before implementation.

## Scope

- Teams Power Apps templates.
- Power Apps Samples.
- Creator Kit.
- CoE Starter Kit.
- Power Apps Test Engine.
- ALM Accelerator as historical reference only.

## Acceptance Criteria

- Each candidate is classified as reuse, reference, avoid, or defer.
- Any reused asset must include license and attribution handling.
