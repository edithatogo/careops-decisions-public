# Track 07: Future Azure And Entra Upgrade

## Goal

Design the later enterprise path that needs Azure, Entra, Microsoft Graph, and admin consent.

## Scope

- Entra app registration.
- Graph calendar, Teams meeting, transcript, file, group, and user APIs.
- Teams meeting extensions and bot notifications.
- Copilot and advanced AI integration.
- Full Dataverse and Power BI/Fabric reporting.

## Acceptance Criteria

- Future dependencies are explicit and not required for MVP.
- Upgrade path does not require replacing the core data model.
