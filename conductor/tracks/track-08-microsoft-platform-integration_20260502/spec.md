# Track 08: Microsoft Platform Integration

## Goal

Integrate the app with Microsoft 365 as deeply as the current environment allows.

## Scope

- Office 365 Users reporting lines and hierarchy.
- Outlook calendar and attendees.
- Teams notifications and app hosting.
- Planner tasks.
- SharePoint/Teams files.
- Later Graph for richer sync and automation.

## Acceptance Criteria

- Integration map distinguishes standard connector MVP from Graph-dependent future work.
- Org hierarchy is cached in Dataverse with last-sync metadata.
