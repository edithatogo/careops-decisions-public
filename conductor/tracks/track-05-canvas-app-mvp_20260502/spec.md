# Track 05: Canvas App MVP

## Goal

Build the Teams tab canvas app experience for governance meetings.

## Scope

- Dashboard, governance body, meeting, agenda, run meeting, minutes, papers, decisions, actions, voting, and settings screens.
- Use the locked data model and flow contracts.

## Acceptance Criteria

- Canvas app source artifacts are stored under `powerplatform/src`.
- MVP supports preparing, running, minuting, and following through on a meeting.
