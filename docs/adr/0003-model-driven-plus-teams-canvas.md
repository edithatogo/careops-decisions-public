# ADR 0003: Model-Driven Admin Plus Teams Canvas Workflow

## Status

Accepted.

## Context

Administrators need structured Dataverse administration. Meeting users need a Teams-friendly workflow for agendas, papers, minutes, decisions, actions, and review.

## Decision

Use a model-driven app for administration and a lightweight Teams/canvas app for meeting workflows.

## Consequences

- Dataverse model quality matters before polished UI.
- The canvas app should be optimized for chairs, secretaries, members, and auditors.
- Administrative tables and configuration should not be hidden inside the Teams workflow app.
